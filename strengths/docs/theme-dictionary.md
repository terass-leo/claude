## 領域: 動かす力

### 完遂ドライブ（T01）

**定義**　決めたことを最後までやり切り、成果が出るまで熱量を落とさない力。

| 観点 | 内容 |
|---|---|
| 現れやすい行動 | 締切前でも粘って詰め切る<br>停滞している案件を再起動させる<br>数字目標があると出力が上がる |
| 向いている仕事の型 | 期限の重いプロジェクトの推進役<br>立ち上げ直後の泥臭いフェーズ<br>未達案件のリカバリー |
| 出すぎたときの副作用 | 手段が目的化して走り続ける<br>周囲の消耗に気づかない<br>撤退判断が遅れる |
| 1on1で確かめたい問い | 最近「やり切った」と感じた仕事は何ですか。逆に、走り続けたことで周囲が置いていかれた場面はありませんでしたか。 |

| 観点 | 内容 |

| 1on1で確かめたい問い | 今いちばん段取りが効いている案件と、逆に計画どおりに進まずストレスを感じている案件はどれですか。 |

## 領域: 巻き込む力

### 主導性（T04）

**定義**　結論の出ない場に自ら踏み込み、決めて動かす力。

| 観点 | 内容 |
|---|---|
| 現れやすい行動 | 議論を収束させて結論を出す<br>責任のある役割を引き受ける<br>誰も動かない局面で先に動く |
| 向いている仕事の型 | 新規PJのリード<br>難度の高い交渉・調整<br>意思決定が滞っている会議体の再設計 |
| 出すぎたときの副作用 | 議論を打ち切りすぎる<br>周囲が意見を出しにくくなる<br>独断に見える |
| 1on1で確かめたい問い | 最近、自分が結論を出して前に進めた場面はどこですか。周囲が意見を出しにくくなっていないか、どう確かめていますか。 |
