# tools

MTG中にPC上で使う小道具。単一のHTMLファイルで完結しており、ビルドも依存パッケージもない。

## mtg-whiteboard.html — 板書

会議中に画面共有しながら図を描くための無限キャンバス型ホワイトボード。

### 使い方

いちばん手軽なのは、公開済みのArtifactのURLをブラウザで開くこと（自動保存が効き、画像コピーもそのまま使える）。

ローカルのファイルを使う場合は、このファイルをダブルクリックしてブラウザで開くだけでよい。
社内に置いて共有したい場合は静的ホスティングにそのまま載せられる。

### 道具

| キー | 道具 |
| --- | --- |
| `V` | 選択・移動（ドラッグで範囲選択、`Delete` で削除） |
| `P` | ペン |
| `E` | 消しゴム（なぞった線・図形を消す） |
| `R` `O` | 四角 / 丸 |
| `L` `A` | 直線 / 矢印 |
| `T` | 文字（`⌘Enter` で確定） |
| `N` | 付箋 |
| `X` | レーザーポインタ（画面共有で指すため。盤面には残らない） |
| `1`–`6` | インクの色（付箋の色は `1`–`4`） |

盤面の操作は `space`+ドラッグで移動、ホイール／2本指スワイプで上下左右、`⌘`+ホイールまたはピンチで拡大縮小。
`0` で100%、`F` で全体表示。`?` でショートカット一覧。

### 仕様上のメモ

- **自動保存**: 盤面は `localStorage`（キー `bansho.v1`）に保存され、タブを閉じても続きから使える。ブラウザ・プロファイルごとの保存なので、他人とはリアルタイム共有されない。
- **画像の書き出し**: 「画像をコピー」で盤面をPNGにしてクリップボードへ入れる（Slackや議事録にそのまま `⌘V`）。クリップボードが使えない環境では画像を画面に出すので、右クリックから保存できる。
- **ライト／ダーク**: ブラウザの配色設定に追従する。ライトはホワイトボード、ダークは黒板として、同じ6色のインクをそれぞれ読み替えて描く。色は色番号で保存しているので、あとから配色を切り替えても描いたものはそのまま残る。
